# 📊 Excel - Sales and Finance Analytics Project | AtliQ Hardwares

## 📌 Project Overview
AtliQ Hardwares is a leading hardware company specializing in PCs, printers, mice and computers with a global reach. The company faced challenges in optimizing sales and improving gross margins due to unorganized data.

This project analyzes over 500k+ records and presents insights through Excel reports.

### Problem Statement:
To analyze unorganized sales data and generate insights to improve sales and profitability.

### Project Goal:
To perform ETL, create Sales and Finance reports in Excel and provide data-driven recommendations.
